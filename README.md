## `whoami`

> I am a cybersecurity enthusiast wasting time on **system administration and infrastructure management**, while slowly losing faith in software, human warmth, and any illusion of a "beautiful world". I am currently forcing myself to look into **OSINT, reverse engineering and security research** because at least code behaves logically, even when it's broken.
> 
> People talk about love, happiness, and how the world is a wonderful place. Meanwhile, infrastructure fails, people betray trust faster than a bad commit, and underlying systems collapse under the weight of human incompetence. 
> 
> Cybersecurity is the only thing that makes sense: it doesn't lie to you about how safe you are. Everything else is just poorly documented social engineering.

> **> "Love is just an unhandled exception in human logic.
> > The world isn't beautiful; it's a massive, misconfigured production server waiting for a kernel panic."**

## `background`

### 🖥️ System Administration

> My foundation comes from dealing with broken infrastructure and endless system administration tasks.
> 
> Areas I've wasted too much time on include:
> 
> * Linux server administration (and fixing what breaks)
> * Server configuration and maintenance
> * User and group management (dealing with human error)
> * File and system permissions
> * Access control bypasses in daily practice
> * Service configuration (that rarely works on the first try)
> * Infrastructure troubleshooting
> * Basic network and system security (which is usually an illusion)
> * Automation of repetitive tasks to avoid talking to people
> 
> This experience gave me a bleak understanding of how systems are structured, how poorly services interact, and how a single wrong decision ruins everything — much like human relationships.

---

### 🔎 OSINT

> I am trying to tolerate **Open-Source Intelligence**.
> 
> My interest is narrowed down to the cold, analytical side of information gathering:
> 
> * Open-source information discovery (finding what people tried to hide)
> * Information correlation
> * Digital footprint analysis (people leak everything)
> * Metadata analysis
> * Infrastructure reconnaissance
> * Domain and DNS intelligence
> * Publicly available technical information leaks
> * Building structured investigation workflows
> 
> The goal isn't to be optimistic about privacy or human nature — it's to prove that secrets don't exist if you look closely enough.

---

### ⚙️ Reverse Engineering

> Another area I am reluctantly exploring is **reverse engineering**.
> 
> I am interested in understanding software because developers rarely write clean code — figuring out how binaries actually work, how programs lie to the operating system, and how their behavior can be analyzed without trusting empty marketing claims or source code.
> 
> Current areas of interest:
> 
> * Binary analysis (and dealing with obfuscation)
> * Program behavior analysis
> * Static analysis
> * Dynamic analysis
> * Assembly fundamentals
> * x86/x64 architecture
> * Executable formats
> * Debugging endless segmentation faults
> * Low-level programming concepts
> * Malware analysis fundamentals (because most software behaves like a threat anyway)

> **> "Reverse engineering is a relief compared to human communication: binaries don't pretend to love you before crashing."**
